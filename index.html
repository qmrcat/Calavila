Cala

Només consulta. Clica qualsevol element per saber què és. Pots girar, moure i acostar la càmera.

Clica per construir. Amb el botó dret treus el que hi ha més amunt, sigui quin sigui el mode (al mòbil, amb el botó Treure). Arrossega per girar; arrossegant amb el botó dret, Alt, les fletxes o dos dits, et mous. La roda o el pessic acosten.

El color triat s'aplica al que construeixes; amb Pintar el poses a cases ja fetes. Amb Places auto. (a Configuració), tot buit voltat de tres cases es pavimenta sol. En mode Voltes, clica una casa de dos pisos o més per porxar-la. Clica dos cops un carrer per enlairar-lo un nivell; per pujar-hi, posa-hi una escala al costat en mode Escales.
